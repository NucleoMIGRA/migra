DataMigra repository

The DataMigra repository provides access to the code, tables, and figures used on this platform. It is designed to facilitate replication, reuse, and citation of the published indicators.

Go to repository Núcleo Milenio Migra website

What the repository contains

The repository contains R scripts organized by source, publication-ready figures, figure-ready tables for reproducing visualizations, and a general user guide.

What it is for

It allows users to review how indicators are constructed, reuse tables and figures for research or teaching, and update results when new source data become available.

Repository structure

code/: reproducible scripts organized by source.
tables/: figure-ready tables for reproducing charts.
figures/: final publication-ready visualizations.
README.md: general guidance, sources, and methodological notes.

How to cite and reuse

When reusing a figure or table, cite DataMigra and the corresponding original data source. Whenever possible, use the figure-ready table associated with each chart to support traceability and replication.

Public sources and Transparency requests

Some sections use data downloaded from official open-data websites, while others use records obtained through public-information requests. This distinction is stated on each source page.

Policy briefs

Policy briefs present curated selections of DataMigra indicators and figures to support public discussion, teaching, and communication of descriptive evidence on migration in Chile.
